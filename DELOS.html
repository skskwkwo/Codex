1

제미나이 API 키 설정

설정 탭에서 Google Gemini API 키를 입력하면 Gemini 3.5 Flash / 3.1 Pro 모델을 사용할 수 있습니다.

2

Ollama 로컬 모델

내 컴퓨터에서 ollama list로 확인한 모델을 그대로 사용할 수 있습니다. ollama serve로 서버를 시작하세요.

3

덕덕고 · 웹 리서치 · 크롤링

사이드바에서 원하는 기능을 선택하거나 채팅 입력창 위의 도구 버튼으로 활성화할 수 있습니다.

4

실시간 스트리밍

응답은 토큰 단위로 실시간 스트리밍되어 자연스럽고 빠르게 표시됩니다. 설정에서 끌 수 있습니다.

5

배경화면 · iOS 스타일 토글

설정에서 8가지 우주 테마 배경과 커스텀 URL을 적용하고, 모든 기능은 iOS 스타일 토글로 손쉽게 on/off할 수 있습니다.

DELOS · 부팅 중

🌌 DELOS 소개

DELOS는 우주적 지성과 함께하는 차세대 AI 대화 플랫폼입니다. Google Gemini, Ollama 로컬 모델, 그리고 웹 리서치/크롤링을 하나로 통합하여 사용자에게 가장 자연스럽고 강력한 대화 경험을 제공합니다.

🪐 지원 모델

• Gemini 2.5 Flash (Gemini 3.5 Flash 호환) — 빠른 속도와 균형 잡힌 성능

• Gemini 2.5 Pro (Gemini 3.1 Pro 호환) — 고급 추론과 깊은 사고

• Ollama 로컬 모델 — 모든 로컬 LLM을 그대로 활용

🔍 통합 기능

• 덕덕고(DuckDuckGo) 프라이버시 검색

• 다중 소스 웹 리서치

• URL 기반 웹 크롤링 및 요약

• 실시간 토큰 스트리밍

🎨 디자인

우주와 유니콘이 만난 DELOS 로고 · 빨강/보라/연두/흰색의 우주적 팔레트 · 글래스모피즘 + RGB 빛 효과 · iOS와 Android를 융합한 새로운 UX

🚀 시작하기

1. 설정에서 Gemini API 키 입력

2. Ollama를 사용한다면 ollama serve 실행 후 모델 선택

3. 채팅 입력창에 메시지를 입력하고 전송 버튼(화살표)을 누르세요

4. 덕덕고/웹 리서치/크롤링 도구 버튼으로 기능을 활성화하세요

DELOS는 브라우저에 안전하게 설정을 저장합니다. 계속 진행하면 동의한 것으로 간주됩니다.
